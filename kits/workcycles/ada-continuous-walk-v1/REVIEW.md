# Ada continuous walk source

This five-second source was generated from Ada's retained elevated master. The generation record contains its exact prompt, source hashes, model and 1,400-credit cost. It is one bounded experiment; it does not change the project's default built-in image generation policy or authorize scaling paid video batches.

The decoded chronological sheet shows alternating leg silhouettes and intermediate crossings. Unlike the earlier independently generated sheets, the leading leg does not remain the same through the entire performance. The crown, goggles, braid, waistcoat, tied blouse, breeches and belt remain recognizable. This is useful motion production material, not final animation approval.

One sampled frame (zero-based 5, about 0.417 seconds) touches the bottom source edge. Retain that evidence and exclude it from a usable loop. The source also contains changes in arm shape, tool position, expression and body proportions. A loop selection must be checked at its seam and cannot inherit approval from the master.

The extractor preserves raw decoded frames, native transparent figures, chronological timestamps, a global registration transform, a 256-pixel-cell atlas and an animated sheet preview. Binary alpha and nearest-neighbor scaling preserve hard output edges. They cannot turn softened source detail into authored pixel clusters.

No room actor or Windows executable has been replaced by this candidate.
