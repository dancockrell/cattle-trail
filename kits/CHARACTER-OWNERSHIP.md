# Dedicated character production

User direction: one agent per character. Current three production slots are assigned to Eleanor, the mounted rider, and the rustler. Root handles extraction, cataloguing, room integration, verification and packaging.

| Character | Dedicated agent | Current delivered kits |
|---|---|---|
| Eleanor | weird_west_design | gesture-v2, social-v3 |
| Mounted rider | variable_grid_helper | social-v1 |
| Rustler | herd_direction_audit | state-v2 |

Keep each character's existing source identity, outfit, proportions and camera reference with its owner. Save each source sheet and exact prompt separately. Producers report actual views and states; the integrator records those observed mappings rather than the requested mapping when they differ. Producers do not concurrently edit the shared manifest or room selection.

Whole sprites remain the production approach. The rejected detached-limb experiment is historical evidence only. State kits supply gestures and reactions; they do not count as repaired walking cycles. Additional characters receive their own ownership when they enter the authorized room scope.
